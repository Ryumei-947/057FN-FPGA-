# 057FN——基于 FPGA 的实时图像边缘检测与形状识别系统

## 项目信息

- **作品名称：**057FN——基于 FPGA 的实时图像边缘检测与形状识别系统
- **队伍名称：**流明114514
- **队伍编号：**44262
- **目标器件：**Efinix Titanium Ti60F225
- **开发工具：**Efinity 2026.1.132
- **仿真工具：**ModelSim 10.4
- **工程入口：**`ti60f225_oob.xml`
- **顶层模块：**`ti60f225_oob_top`

本仓库保存最终提交版本 **057FN** 的 FPGA 工程、RTL 源码、IP 配置、约束文件、仿真用例和编译验证记录。

最终版在开发板上进行了约 3 分钟的测试，主要功能运行正常。

## 功能概览

- 摄像头 RAW10 数据采集、中央裁剪、去马赛克和 RGB 输出
- DDR 帧缓存与 32 帧历史记录
- 灰度、中值滤波、保边平滑、Sobel 边缘检测和邻域边缘清理
- 圆形、矩形、三角形、六边形、八边形五类形状识别
- 彩色边缘叠加和分类框色：圆形绿色、矩形白色、三角形黄色、六边形红色、八边形黑色
- LIVE、HOLD、PLAY、COMP 和四分屏显示模式
- PLAY/COMP 中逐帧后退、前进，以及每秒 8 帧快退、快进
- SW0 全链路复位与恢复

## 工程结构

```text
ti60f225_oob.xml       Efinity 工程入口
rtl/                   Verilog/SystemVerilog 源码及 DDR、摄像头、显示模块
ip/                    工程使用的 IP 文件
demo_shapes/           演示图形资源
verification/          ModelSim 用例、运行脚本、日志和验证结果
outflow/               编译输出，包括 bit 文件（若已随仓库发布）
ti60f225_oob.sdc       时序约束
ti60f225_oob.peri.xml  外设配置
Panel_1080p_reg.mem    1080p 面板寄存器配置
```

## 打开工程

1. 安装 Efinity 2026.1.132 或兼容版本，并准备 Ti60F225 器件支持包。
2. 在 Efinity 中打开 `ti60f225_oob.xml`。
3. 确认工程中的 IP 路径、器件型号和板卡引脚约束有效。
4. 首次编译或清理过输出目录后，从 **Synthesis / Compile** 或 **Full Flow** 开始运行，不要直接从 Placement 或 Debugger 起步。
5. 生成的下载文件为 `outflow/ti60f225_oob.bit`。

工程使用 DDR 帧缓存保存历史帧。该架构已向比赛方确认接受。

## 按键操作

| 模式 | 操作 | 功能 |
| --- | --- | --- |
| 任意模式 | SW0 | 全链路复位，恢复后回到 LIVE |
| LIVE | 同时按 SW2 + SW3 约 0.5 秒 | 进入或退出四分屏 |
| LIVE/HOLD | 单独长按 SW3 约 1 秒 | 进入 PLAY，并自动退出四分屏 |
| LIVE/HOLD | SW3 短按 | LIVE 与 HOLD 切换 |
| PLAY/COMP | SW1 短按 | 后退一帧并暂停 |
| PLAY/COMP | SW2 短按 | 前进一帧并暂停 |
| PLAY/COMP | SW1 按住约 0.5 秒 | 以每秒 8 帧快退，松开停止 |
| PLAY/COMP | SW2 按住约 0.5 秒 | 以每秒 8 帧快进，松开停止 |
| PLAY | SW3 短按 | 暂停或继续自动回放 |
| 任意模式 | 同时按 SW1 + SW2 约 0.5 秒 | 显示或隐藏状态文字 |
| LIVE/HOLD | SW1 或 SW2 单键松开 | 调整边缘检测低阈值 |

## 版本说明

057FN 相对 057FN00 的生产代码修改仅涉及三角形面积补偿限值的小幅收紧。具体差异见 [`verification/source_changes_057FN.md`](verification/source_changes_057FN.md)。其余形状判定、SW0 复位、五种框色、四分屏、回放、帧对比和时序约束均保留。

由于 Canny 算法在开发版实际测试中效果不佳，057FN 不应用 Canny 算法。

## 注意事项

- 该工程面向指定 Efinix Ti60F225 板卡和摄像头连接，换用其他硬件前需要重新核对引脚、时钟和摄像头配置。
- `work_syn/`、`work_pnr/` 中的大型中间文件可由完整流程重新生成。原验证快照还核对 `work_dbg/debug_top.v`，保留原验证流程时应同时保留该文件。
- 形状识别验证记录包含合成图形场景；实际识别效果仍与目标尺寸、轮廓质量、采样位置和背景有关。
- 发布预编译 bit 时，附上与该次构建对应的时序报告及校验值；也可发布完整源码工程，由评审者通过 Efinity 完整流程重新编译。
